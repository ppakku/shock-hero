# 공포 모드 설계: 밤의 고철 공장

> **괴물 변경 (2026-10-31):** 공포 모드의 괴물은 파쇄자가 아니라 민성님 아들이 그린 캐릭터다. 긴 목, 달걀 머리, 동그랗게 뜬 눈, 이를 드러낸 웃음, 뾰족하고 긴 팔, 발톱 달린 발을 가졌다. 그림의 비율대로 3D 몸을 만들고 얼굴과 피부는 사진을 참고로 Gemini 가 칠한 그림을 입힌다. 이름은 세이노다. 아래 글의 파쇄자는 이 괴물로, 톱날 소리는 거친 숨소리와 발톱 소리로, 잡히는 장면의 톱날은 얼굴이 화면 가득 다가오는 장면으로 읽는다. 쓰러뜨릴 수 없다는 규칙과 행동 상태는 그대로다.

쇼크 히어로에 1인칭 공포 모드를 더한다. 첫 버전은 맵 하나, 한 판 10~15분이다. 무서운지 확인한 뒤 맵을 늘린다.

## 정한 것

| 항목 | 결정 |
|---|---|
| 무서움 | 꽤 무서운 중간 단계. 어둠, 잡히는 장면, 놀람 장면은 있고 피와 잔인한 표현은 없다 |
| 놀이 방식 | 숨고 도망치기가 기본. 쇼크 펀치로 괴물을 몇 초 멈출 수 있지만 쓰러뜨릴 수는 없다 |
| 기기 | PC와 태블릿. 휴대폰은 첫 버전에서 뺀다 |
| 무대와 괴물 | 밤의 고철 공장, 파쇄자 |
| 만드는 방식 | 지금 게임 안에 Three.js 3D 화면을 새 모드로 더한다 |

## 플레이 흐름

1. 타이틀에서 공포 모드를 고른다. "꽤 무섭다"는 안내와 기기에 맞는 조작법이 나오고, 시작 버튼을 눌러야 시작한다.
2. 짧은 이야기: 밤에 공장을 조사하다 문이 잠기고, 로봇 볼트와 통신이 끊긴다.
3. 퓨즈 3개를 찾아 정문 전원에 꽂고 정문으로 나가면 탈출이다.
4. 탈출하면 보석을 받고, 한 번도 잡히지 않았으면 더 받는다. (2026-11-01 변경: 탈출 보석은 기기 날짜로 하루의 첫 탈출에만, 안 잡힌 보너스는 처음 한 번만 준다. 끝 화면은 실제로 받은 보석을 말한다.)

퓨즈는 맵에 적힌 후보 자리 중에서 판마다 뽑는다. 모든 퓨즈는 시작 지점에서 걸어갈 수 있는 자리에 놓인다.

## 플레이어의 행동

- **손전등:** 켜면 잘 보이지만 파쇄자의 시야에서 빛이 들킨다. 끄면 아주 어두운 윤곽만 보인다. 배터리 제한은 두지 않는다.
- **걷기와 달리기:** 달리기는 빠르지만 큰 소리가 나서 파쇄자가 듣는 거리가 늘어난다.
- **숨기:** 사물함에 들어가면 문틈으로 밖이 보인다. 안에 있으면 시야로 들키지 않는다. 다만 수색 중인 파쇄자는 주변 사물함을 뒤질 수 있다.
- **쇼크 펀치:** 벽의 전기 상자에서 충전한다. 한 번에 1회분만 들 수 있고 상자마다 한 번만 쓴다. 맞히면 파쇄자가 약 5초 멈춘다.

## 파쇄자의 행동

상태는 네 가지다.

| 상태 | 하는 일 | 다음 상태 |
|---|---|---|
| 순찰 | 맵에 적힌 지점을 돈다 | 소리나 불빛을 알아채면 조사, 주인공을 보면 추격 |
| 조사 | 알아챈 자리로 간다 | 주인공을 보면 추격, 아무것도 없으면 순찰 |
| 추격 | 주인공을 쫓는다 | 놓치면 수색, 닿으면 잡기 |
| 수색 | 놓친 자리 주변과 사물함을 뒤진다 | 주인공을 찾으면 추격, 시간이 다 되면 순찰 |

펀치에 맞으면 어느 상태에서든 멈추고, 깨어나면 수색을 시작한다. 벽을 지나가지 않고 칸 맵 위의 길 찾기로 움직인다.

## 잡혔을 때

톱날이 화면 가득 다가오고 화면이 꺼진다. 찾은 퓨즈는 유지하고 시작 지점에서 다시 시작한다. 파쇄자는 멀리 떨어진 순찰 지점으로 옮긴다. 잡히는 횟수에 제한은 없다.

## 화면

- **맵:** 한 층, 방 10개쯤. 칸 표로 적는다. 벽, 문, 사물함, 전기 상자, 퓨즈 후보, 순찰 지점, 놀람 장면 자리를 표에 함께 적는다.
- **그림:** 벽, 바닥, 기계, 사물함 문은 Gemini 로 그린다.
- **빛:** 손전등 하나만 그림자를 만든다. 깜빡이는 비상등을 군데군데 두고 나머지는 어둠이다.
- **파쇄자 모형:** 2D 그림을 세우지 않고 원통 몸통에 녹슨 철판 그림을 입힌다. `shredder_saw.png` 톱날이 실제로 돌고, 다리는 단순한 관절로 움직인다. 배 구멍에서 붉은빛이 새어 나온다.
- **놀람 장면:** 정해진 자리에서 몇 번 나온다. 번쩍임은 기존 `settings.lowFx` 를 따른다.

## 소리

기존 `sfx.js` 처럼 코드로 합성한다. 배경 음악은 낮은 지속음, 바람 소리, 가끔 울리는 쇳소리로 만들고 시작 버튼을 누른 순간 시작한다. 쿵쿵 걸음, 톱날, 숨소리, 심장 소리를 만든다. 파쇄자 소리는 Web Audio 의 입체 음향으로 방향이 들리게 하고, 가까울수록 심장 소리가 빨라진다. `settings.muted` 를 따른다.

## 조작

| 동작 | PC | 태블릿 |
|---|---|---|
| 이동 | WASD | 왼쪽 조이스틱 |
| 시점 | 마우스 (마우스 잠금) | 오른쪽 화면 끌기 |
| 달리기 | Shift | 조이스틱 끝까지 밀기 |
| 손전등 | F | 화면 버튼 |
| 줍기, 숨기, 나오기 | E | 화면 버튼 |
| 쇼크 펀치 | 왼쪽 클릭 | 화면 버튼 |
| 일시정지 | Esc | 화면 버튼 |

## 코드 구조

- `src/horror/`: 공포 모드 화면 전부. 3D 그리기, 파쇄자 모형, 소리, 입력, 화면 글자. 타이틀에서 고를 때 동적 import 로 내려받아서, 기존 게임 첫 로딩에 Three.js 가 들어가지 않는다.
- `src/horror/maps/`: 맵 데이터.
- `src/logic/horror*.js`: 화면과 상관없는 계산. 파쇄자 상태 변화, 칸 길 찾기, 소리가 들리는 거리, 시야 판정, 퓨즈 뽑기, 잡혔을 때 규칙, 보상 계산.
- `src/config/balance.js` 의 `horror` 묶음: 조절할 숫자 전부.
- 타이틀에는 공포 모드 입구만 더한다. 기존 스테이지와 보스 코드는 바꾸지 않는다.

공포 모드가 켜지면 Phaser 장면은 멈추고 Three.js 캔버스를 위에 띄운다. 끝나면 캔버스와 3D 자원을 치우고 타이틀로 돌아온다.

## 저장

기존 저장에 탈출 횟수와 잡히지 않은 탈출 여부를 더한다. 값이 없는 예전 저장은 0 으로 읽는다. 보상 보석은 기존 `gems` 에 더한다. 판 도중에는 저장하지 않으므로 나가면 처음부터 시작한다.

## 속도

- 태블릿에서 초당 30장 이상을 목표로 한다.
- 느리면 화면 해상도를 자동으로 낮춘다.
- 어둠에 묻혀 안 보이는 먼 구역은 그리지 않는다.

## 문제가 생길 때

- WebGL 을 켤 수 없거나 내려받기가 실패하면 안내를 띄우고 타이틀로 돌아간다.
- 탭을 벗어나거나 PC 에서 마우스 잠금이 풀리면 일시정지한다.

## 확인

- 자동 테스트: 파쇄자 상태 변화, 길 찾기가 벽을 지나지 않음, 퓨즈가 항상 갈 수 있는 자리에 놓임, 소리 거리, 잡혔을 때 퓨즈 유지, 예전 저장 읽기.
- 화면 없는 Chrome 봇: 탈출하는 판과 잡히는 판을 끝까지 돌려 오류가 없는지 본다.
- 캡처: 손전등을 켰을 때와 껐을 때 화면이 실제로 보이는지 본다.
- 사람이 확인: 실제 태블릿 속도와 무서운 정도.

## 만드는 순서

1. 그림 없이 벽, 손전등, 걷기만 되는 작은 맵으로 태블릿 속도를 확인한다.
2. 파쇄자의 행동과 모형.
3. 소리.
4. 퓨즈, 사물함, 전기 상자, 잡기, 탈출.
5. Gemini 그림과 전체 맵, 놀람 장면, 보상.

## 첫 버전에서 뺀 것

휴대폰, 2인 플레이, 맵 여러 개, 다른 괴물, 판 도중 저장, 손전등 배터리, 다른 영웅 선택.
