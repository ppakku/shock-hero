# 공포 모드 어른용 판: 해 질 녘 숲과 처녀귀신

2026-11-07 사용자와 정한 내용. 화면 시안: https://claude.ai/artifact/W39PpH7tDHcwY7wGuijHhd (확정)

## 정한 것

- 새 판 하나: 숲 맵(`forest`)과 처녀귀신(`maiden`)은 항상 짝이다. 마지막 밤처럼 MAP_IDS, MONSTER_IDS 밖에 둔다. 랜덤, 도장판, 오늘의 밤에는 나오지 않는다.
- 고르기 화면 맨 아래 "어른용: 해 질 녘 숲, 처녀귀신" 칸. 처음부터 열려 있다. 누를 때마다 확인 창(들어가기, 돌아가기)이 뜨고 Enter 는 돌아가기에 먼저 걸린다.
- 수위: 이 판만 어른도 무서운 수준. 피와 상처는 없다. 소개 맨 위 경고는 "어른도 무서워요. 불을 켜고, 혼자 하지 마세요."
- 이름은 "처녀귀신". 남은 시간 숫자는 보여 주지 않는다. 하늘 색과 짧은 알림만.
- 보상: 보통 판처럼 하루 첫 탈출에 보석(`settleEscape` 그대로). 도장은 없다(`addStamp` 가 isRound 아닌 판을 무시한다). 끝 화면 "다시 하기"는 확인 창 없이 숲으로 바로 들어간다.
- 그림은 Gemini 로 최대한 그린다. 원본은 `~/workspace/shock-hero-art/forest/`.

## 해 질 녘 (dusk)

- `src/logic/horrorDusk.js` 순수 함수 `duskAt(t, k)` 가 판 시작 뒤 지난 초를 받아 `{ level 0..1, stage: 'glow'|'twilight'|'night' }` 와 하늘, 안개, 주변광 색을 준다.
- 단계: 노을 0~180초, 어스름 180~480초, 밤 480초부터. 숫자는 `balance.horror.forest.dusk` 에 둔다.
- 단계가 바뀔 때 HUD 알림 한 줄: 어스름 "어디선가 흐느끼는 소리가 들린다", 밤 "해가 완전히 졌다".
- HorrorGame 이 매 프레임 `this.ambient`, 안개 색과 거리, 하늘 색을 dusk 값으로 갱신한다. 놀람과 잡힘 뒤 되돌릴 때도 그 순간의 dusk 값으로 돌아간다.

## 숲 맵

- `src/horror/maps/forest.js`. 기존 글자 표기 그대로(`#` 은 나무와 덤불, `L` 은 속 빈 고목, `G` 는 철문, `N` 쪽지, `F` 퓨즈 자리와 쪽지 자리 등). 탈출 순서(퓨즈, 열쇠, 잠긴 길 둘, 비밀번호 쪽지, 철문)도 기존과 같다. 잠긴 문 A, B 는 사슬 감긴 나무 울타리 문으로 칠한다.
- 테마 `outdoor: true`: 천장을 만들지 않고 하늘 돔(Gemini 노을 하늘)을 씌운다. `#` 칸은 상자 벽 대신 나무줄기(인스턴스)와 수관, 덤불 카드로 그린다. 시야 가림 판정은 그대로 `#` 이다.
- 장식: 장승, 서낭당 돌무더기, 가지에 걸린 머리카락. 벽등과 관은 없다.
- 테스트 `horrorMaps` 의 크기, 방, 열쇠 순서 규칙을 숲에도 그대로 적용하고, 천장 관련 규칙만 outdoor 에서 뺀다.

## 처녀귀신 규칙

- `tickStalker` 에 `maiden` 갈래. 세이노 규칙(소리, 손전등 빛을 알아챔)을 바탕으로 dusk 단계에 따라 값이 바뀐다.
  - 노을: 걷기 느림, 듣는 거리 짧음, 쫓지 않고 멀리서 모습만 보였다 사라진다.
  - 어스름: 소리와 빛을 알아채고 쫓는다. 플레이어 시야 밖에 `blinkAfter` 초 있으면 플레이어 가까운 나무 옆 칸으로 순간이동(`blink` 사건).
  - 밤: 쫓는 속도가 플레이어 달리기에 가깝고, 순간이동 거리가 짧아져 등 뒤에 나타난다.
- 쇼크: 비명과 함께 사라지고(`sendAway`) 몇 초 뒤 다른 곳에 나타난다.
- 숫자는 `balance.horror.monsters.maiden` 에 단계별로 둔다.

## 연출과 소리

- 목소리 `maiden`: 합성음으로 흐느낌(멀리), 흥얼거림(중간), 귓가 속삭임(가까이). 발소리 대신 옷자락 스치는 소리.
- 잡힘: 긴 머리 사이 하얀 얼굴이 화면 가득 다가온다(Gemini 얼굴 그림).
- 놀람 칸: 손전등 끝에 얼굴, 뒤돌면 바로 뒤에 서 있다가 사라짐.

## 귀신 모델

- `src/horror/creatureMaiden.js`, `CreatureBase` 를 이어받는다. 떠 있는 소복 몸통(아래로 갈수록 투명), 앞뒤 머리카락 띠, Gemini 앞, 뒤 그림을 감싼다. 발이 없고 위아래로 천천히 떠오른다.
- 테스트 기준은 기존 모델과 같다(그리기 12번 이하, 삼각형 8000 미만, 키 2.4~2.95m, 그림 파일 존재).
