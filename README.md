# 쇼크 히어로: 몬스터 브레이커

도시를 부수는 돌연변이 괴물과 싸우는 2D 액션 게임입니다. 브라우저에서 바로 플레이할 수 있습니다.
설계 문서는 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md), 만들면서 정한 것들은 [docs/DECISIONS.md](docs/DECISIONS.md)에 있습니다.

## 조작법

| 동작 | 키 |
|---|---|
| 이동 | A / D 또는 ← → |
| 점프 | Space (W, ↑ 도 됨). 짧게 누르면 낮게, 길게 누르면 높게. 공중에서 한 번 더 누르면 더블 점프(빙글 돌며 한 번 더 뜀, 땅에 닿으면 다시 생김). 물속에서는 헤엄 |
| 펀치 | J 또는 마우스 왼쪽 |
| 충전 펀치 | J 를 꾹 눌렀다가 떼기. 파란 링이 다 차면 MAX, 파란 에너지탄이 앞으로 날아감 |
| 어퍼컷 (위쪽 공격) | W 나 ↑ 를 누른 채 펀치. 머리 위 하늘의 적을 때림. 충전하면 에너지탄이 위로 (걸으면서 쏘면 대각선 위로) |
| 궁극기 | L. 적을 때리면 파란 궁극기 게이지가 참. 꽉 차면 뛰어올라 땅을 찍고, 화면 안의 모든 적에게 큰 피해 |
| 대시 | K 또는 Shift. 대시 중에는 공격을 맞지 않음 |
| 일시정지 | Esc (일시정지 화면에서 H: 화면 흔들림, F: 효과 줄이기, M: 소리, T: 타이틀로) |

**효과 줄이기**: 노트북이 느리거나 번쩍이는 화면이 불편하면 일시정지 화면에서 F (태블릿은 "효과" 버튼)를 누르세요. 빛 번짐, 아지랑이, 멈칫, 화면 확대, 번쩍임을 끄고 불꽃 수를 줄입니다. 화면 흔들림은 H 로 따로 끕니다.

### 태블릿 (키보드 없음)

손가락 화면인 기기로 열면 화면 위에 조작이 나옵니다. 왼쪽 절반은 조이스틱입니다: 아무 데나 엄지를 대면 그 자리가 가운데가 되고, 끄는 방향으로 걷습니다. 위쪽(위에서 좌우 45도 안)으로 밀면 걷지 않고 위를 조준해서, 펀치하면 어퍼컷, 충전하면 에너지탄이 바로 위로 나갑니다. 오른쪽 아래는 점프, 펀치(꾹 눌렀다 떼면 충전 펀치), 대시, 궁극기 버튼, 오른쪽 위 II 는 일시정지입니다. 버튼은 게임이 잘 보이게 흐릿하고 누르는 동안만 또렷해집니다. 물속에서는 점프 버튼을 꾹 눌러 헤엄칩니다. 타이틀 카드는 한 번 누르면 고르고 한 번 더 누르면 시작합니다. 결과 화면과 일시정지 화면에도 누르는 버튼이 나옵니다. 버튼 위치와 크기는 `src/ui/touch.js` 의 `TOUCH_BUTTONS`, 조이스틱은 `STICK` 숫자로 바꿉니다. 컴퓨터에서 확인하려면 주소 끝에 `?touch` 를 붙입니다. 아이패드는 사파리 공유 메뉴에서 "홈 화면에 추가" 하면 주소창 없이 꽉 찬 화면으로 열립니다.

### 휴대폰

태블릿과 같은 화면 버튼으로 합니다. 휴대폰은 게임 화면이 원래의 60 ~ 70% 로 줄어서, 화면 짧은 쪽이 600 보다 작은 기기는 휴대폰으로 보고 이렇게 바꿉니다.

- 화면 버튼이 더 크고 가장자리로 붙습니다. 가장 작은 버튼도 실제 화면에서 지름 44px 이상입니다. 크기는 `src/ui/touch.js` 의 `PHONE_BUTTONS`, `PHONE_PAUSE`, `PHONE_STICK` 숫자로 바꿉니다.
- 16 보다 작은 글자를 조금 키웁니다 (`src/ui/text.js` 의 `textSize`).
- 휴대폰을 세로로 들면 "가로로 돌려 주세요" 화면이 나오고, 하던 스테이지는 일시정지됩니다.
- 다른 앱으로 넘어가면(전화, 알림) 하던 스테이지가 일시정지됩니다. 돌아와서 계속하기를 눌러야 움직입니다. 컴퓨터와 태블릿도 같습니다.
- 타이틀 왼쪽 위 "전체 화면" 버튼: 안드로이드는 주소창 없이 꽉 찬 화면이 되고 가로로 고정됩니다. 아이폰은 전체 화면이 안 돼서, 누르면 "홈 화면에 추가" 하는 방법을 알려 줍니다. 홈 화면에 추가하면 쇼크 히어로 아이콘이 생깁니다.
- 함께하기 중에 방장이 다른 앱으로 넘어가면 친구 화면에 "기다려 주세요" 가 나옵니다. 친구가 넘어가면 2P 가 누르던 키를 다 뗀 걸로 칩니다 (혼자 계속 걸어가지 않게).
- 함께하기 방장은 게임을 돌리면서 화면을 영상으로 보내야 해서, 휴대폰보다 컴퓨터나 태블릿이 좋습니다.

컴퓨터에서 확인하려면 주소 끝에 `?touch&phone` 을 붙입니다.

## 시작 전에 고르는 것 (타이틀 화면)

타이틀 화면은 흑백 만화 그림체입니다 (docs/title_design.png 오른쪽 그림). 회색 연기 낀 불타는 도시, 옥상 위에서 망토를 휘날리는 주인공, 철판에 적힌 조작법, 사진처럼 핀으로 꽂은 스테이지 카드가 나옵니다. 그림은 모두 코드로 그립니다 (src/ui/titleArt.js). 스테이지 파일에 `titlePhoto: 'water'` 처럼 적으면 카드 사진 장면(city, forest, lava, ice, castle, water)을 고를 수 있습니다.

스테이지 카드 아래 버튼 줄에서 고릅니다. ↓ 키로 버튼 줄로 내려가 ← → 로 고르고 Enter 를 누르거나, 마우스로 눌러도 됩니다.

- **난이도:** 쉬움, 보통, 어려움.
  - 쉬움: 몬스터 수가 적고, 특수 몬스터 일부가 초록 몬스터로 바뀝니다. 몬스터가 약하고 공격 신호가 깁니다. 보스는 체력이 적고 느립니다.
  - 어려움: 몬스터가 더 많고 다양하며 튼튼하고 빠르고 아픕니다. 보스는 더 튼튼하고 아프고 빠르며, 공격 두 개를 동시에 겹쳐 쓰는 일이 많습니다.
  - 모든 난이도에서 뒤 스테이지일수록 몬스터와 보스의 체력과 공격력이 오릅니다. 보통과 어려움은 내 레벨이 스테이지 예상 레벨보다 높으면 몬스터도 따라 세지고(보통은 절반만), 몬스터가 한 번 비틀거린 뒤 잠깐은 맞아도 멈추지 않습니다.
- **조작:** 기본(WASD + J K L) 또는 방향키 + A S D(A 펀치, S 대시, D 궁극기).
- **레벨 초기화:** 레벨, 경험치, 레벨 업 카드, 보물, 스테이지 기록을 모두 지우고 처음부터 다시 쌓습니다. 한 번 더 확인한 뒤 지웁니다. 난이도, 조작, 소리 설정은 남습니다.
- **함께하기 (C 키):** 친구와 인터넷으로 둘이서 합니다. 아래 "함께하기" 를 보세요.

## 주인공

모험 지도 오른쪽 위 카드를 누르거나 H 키로 고릅니다. 버튼은 같고 싸우는 방법이 다릅니다. 숫자는 `src/config/balance.js` 의 `heroes` 에서 바꿉니다.

| 주인공 | 특징 | 공격 | 꾹 눌렀다 떼기 | 대시 | 궁극기 |
|---|---|---|---|---|---|
| 쇼크 히어로 | 기본 | 펀치 | 충전 펀치 | 대시 | 쇼크 임팩트 |
| 번개 사수 | 멀리서 쏨, 체력 적음 | 번개탄 연사 | 레이저 (뚫고 지나감) | 대시 | 번개비 |
| 강철 거인 | 느리지만 셈, 체력 많음 | 망치 내려찍기 | 회오리 | 몸통 박치기 | 대지진 |
| 바람 닌자 | 빠름, 체력 조금 적음 | 짧게 날아가는 표창 | 돌진 베기 (적을 뚫고 지나가며 벰) | 대시 | 회오리 베기 |
| 얼음 마법사 | 적을 느리게 함, 체력 조금 적음 | 천천히 날아가는 얼음탄 | 얼음 폭발 (멀리서 터지고 맞은 적이 잠깐 느려짐) | 대시 | 눈보라 (화면 전체, 맞은 적이 느려짐) |

느려진 몬스터는 파랗게 보입니다. 보스는 느려지지 않습니다. 겨루기에서는 상대 주인공도 느려집니다.

## 함께하기 (친구와 인터넷으로 둘이서)

1. 한 사람(방장)이 타이틀의 **함께하기** 에서 **방 만들기** 를 누르면 5 자리 방 코드(예: `K 7 Q 2 M`)가 나옵니다. 헷갈리는 글자(0, O, 1, I, L)는 쓰지 않습니다.
2. 친구는 자기 기기에서 **함께하기** → **방 참여** 를 누르고 그 코드를 넣은 뒤 Enter(또는 들어가기)를 누릅니다.
3. 방장 화면에 "친구가 들어왔어요!" 가 나오면 Enter 로 모험 지도를 열고 스테이지를 고릅니다. 친구는 그동안 기다립니다.
4. 게임이 시작되면 친구의 주인공이 **2P** 로 나옵니다. 친구가 고른 주인공(쇼크 히어로, 번개 사수, 강철 거인, 바람 닌자, 얼음 마법사)으로 나옵니다.

- 같은 와이파이가 아니어도 됩니다. 컴퓨터와 태블릿이 섞여 있어도 됩니다.
- 게임은 방장 기기에서 돌아갑니다. 친구 기기에는 방장 화면이 영상으로 보이고, 친구가 누른 키만 방장에게 갑니다. 효과음은 친구 기기에서 직접 납니다.
- 몬스터와 보스는 가까운 사람을 노리고, 공격에 닿은 사람은 모두 다칩니다. 보물 힘은 둘이 함께 씁니다.
- 한 명이 쓰러지면 5 초 뒤 친구 옆에서 체력 절반으로 다시 일어납니다. 둘 다 쓰러지면 실패입니다.
- 카메라는 두 사람의 가운데를 따라가고, 두 사람은 화면 밖으로 멀어지지 못합니다.
- 친구가 나가도 방은 그대로입니다. 같은 코드로 다시 들어오면 이어서 합니다.
- 방장이 레벨 업 카드를 고를 때는 게임이 멈추지 않고 화면 위쪽에 작은 카드 줄이 뜹니다. 고르는 동안 1P 는 노란 방울 안에서 멈춘 채 무적이고, 친구는 계속 싸웁니다.
- 위쪽 왼쪽 체력은 1P(방장), 오른쪽 위 노란 칸은 2P(친구) 체력입니다. 친구 화면에는 "▲ 내 체력 (2P)" 가 붙어 있습니다.
- 안내판과 볼트 대사는 방장 조작 키로 나오므로, 친구 화면에는 스테이지가 시작될 때 친구 자기 조작법이 7 초 동안 뜹니다.
- 친구는 Esc 를 두 번(2 초 안에) 누르거나 나가기를 두 번 눌러야 방에서 나갑니다 (실수로 나가지 않게).
- 연결은 PeerJS(무료 공개 중개 서버)로 처음에 서로를 찾은 뒤, 두 기기가 직접 주고받습니다. 직접 길이 막힌 와이파이에서는 PeerJS 의 중계 서버를 거칩니다. 코드는 `src/net/coop.js`, 방 화면은 `src/scenes/RoomScene.js`, 친구 화면은 `src/scenes/GuestScene.js` 입니다.
- 친구 주인공은 친구 기기의 레벨, 레벨 업 카드, 상점 강화로 나옵니다. 같이 얻은 보물, 경험치, 클리어(별, 보석, 다음 스테이지 열림, 기록)는 친구 기기에도 저장되고, 친구 화면 위쪽에 "내 기록" 으로 잠깐 보입니다. 레벨이 올라 생긴 카드는 친구가 혼자 할 때 고릅니다.

### 겨루기 (5 판 3 선승)

친구가 방에 들어오면 방장이 **겨루기** (V 키)를 고를 수 있습니다. 먼저 두 사람이 주인공을 고릅니다. 친구도 같은 화면을 보며 자기 왼쪽 오른쪽 키로 고르고, 공격이나 점프로 결정합니다. 여기서 고른 주인공은 이번 겨루기에만 쓰이고, 한 번 더 할 때 다시 고를 수 있습니다.

서로 때려서 상대 체력을 0 으로 만들면 한 판을 이기고, 먼저 세 판을 이기면 우승입니다.

- 레벨, 강화 카드, 상점 강화는 쓰지 않습니다. 주인공마다 다른 체력과 기술은 그대로입니다.
- 한 판은 60 초입니다. 시간이 끝나면 남은 체력 비율이 높은 쪽이 이기고, 같으면 승수 없이 다시 합니다.
- 궁극기는 매 판 0 에서 시작하고, 한 방 피해는 상대 최대 체력의 35% 까지입니다. 대시로 피할 수 있습니다.
- 경험치, 보석, 도감, 기록은 바뀌지 않습니다. 친구가 나가면 방 화면으로 돌아갑니다.
- 수치는 `src/config/balance.js` 의 `versus` 에서 고칩니다.

## 게임 흐름

스테이지는 40개이고, 냥코대전쟁처럼 **모험 지도**에서 고릅니다. 타이틀에서 Enter(또는 "모험 지도" 판)를 누르면 지도가 열립니다. 1장(스테이지 1 ~ 10), 2장(11 ~ 20), 3장 폭풍의 땅(21 ~ 30), 4장 마왕의 세계(31 ~ 40)로 나뉘고, 길 위의 점을 ← → 로 고르고 Enter 로 출발합니다. Q / E 로 장을 넘기고, Esc 는 타이틀입니다. 처음 하거나 레벨 초기화를 했으면 지도는 스테이지 1 에서 열리고, 해 본 적이 있으면 마지막으로 들어간 스테이지(체크포인트가 있으면 그 스테이지)에서 열립니다. 잠긴 스테이지도 골라서 이름과 보스를 볼 수 있지만 출발은 못 합니다. 점을 한 번 누르면 고르고 한 번 더 누르면 출발합니다(태블릿, 마우스). 점 아래에 별 3개, 아래 설명판에 보스 이름, 보물, 최고 기록이 나옵니다. 2장은 스테이지 10 을 깨면 열립니다. 스테이지가 하나 넘어갈 때마다 몬스터와 보스가 조금씩 세지고, 2장에서는 그 오름폭이 반으로 줄어듭니다(`src/logic/difficulty.js` 의 `STAGE_RAMP`).

| 스테이지 | 이름 | 새로 나오는 것 | 보스 |

1. 몬스터를 **모두** 잡아야 빨간 보스 문이 열립니다. 화면 위에 "남은 몬스터" 수가 나옵니다.
2. 몬스터는 가끔 하트를 떨어뜨립니다. 먹으면 체력이 찹니다.
3. 보물 상자는 스테이지 1 의 3개부터 스테이지 40 의 11개까지 늘어납니다(모두 304개). 자리는 들어올 때마다 무작위로 바뀌고, 뒤 스테이지일수록 높은 발판에 숨습니다. 먹으면 사라지고, 한 번 찾은 보물은 다시 나오지 않습니다. 보물은 경험치 대신 **잠깐 동안 특별한 힘**을 줍니다(아래 표).
4. 보스 문을 지나면 초록 깃발(체크포인트)에서 체력이 다 찹니다. 여기부터는 쓰러져도 보스 앞에서 다시 시작합니다.
5. 보스는 팔이 바닥에 박혀 있을 때("지금! 때려!")만 팔에 피해가 들어갑니다. 팔을 다 부수면 코어가 드러납니다.
6. 경험치는 몬스터와 보스(팔, 날개, 마지막 일격)를 쓰러뜨려야 얻습니다. 레벨이 오르면 최대 체력이 10 늘고, 게임이 멈추면서 **레벨 업 카드**를 한 장 고릅니다.

**별과 보석:** 스테이지마다 별이 3개 있습니다. 타이틀 카드에 금색(받음)과 회색(아직)으로 보입니다.

| 별 | 받는 법 |
|---|---|
| 1 | 스테이지 깨기 |
| 2 | 그 스테이지 보물 전부 찾기 (여러 번에 나눠 찾아도 됨) |
| 3 | 한 번도 쓰러지지 않고 깨기 (체크포인트에서 다시 시작하면 안 됨) |

보석은 보물을 처음 찾으면 2개, 스테이지를 깰 때마다 1개, 새 별마다 3개를 받습니다(`balance.js` 의 `gems`). 보석이 생기기 전 저장은 지금까지 한 만큼 보석을 한꺼번에 받습니다.

**보석 상점:** 타이틀에서 B 키나 "상점" 버튼으로 엽니다. 산 것은 영구히 남습니다(레벨 초기화하면 지워짐). 값과 효과는 `balance.js` 의 `shop`.

| 물건 | 효과 | 값 |
|---|---|---|
| 튼튼한 몸 | 최대 체력 +20 (3단계) | 8, 14, 20 |
| 하트 행운 | 하트가 10% 더 자주, 5 더 채움 (2단계) | 6, 12 |
| 오래가는 힘 | 보물 힘 시간 +25% (2단계) | 8, 14 |

| 궁극기 반 충전 | 궁극기 게이지 절반을 채우고 시작 | 15 |

레벨 업 카드 (← → 와 Enter, 숫자 1 ~ 4, 또는 마우스 클릭. 카드마다 최고 Lv 5):

| 카드 | 한 번 고를 때마다 |
|---|---|
| 공격력 | 모든 공격 +12% (Lv 5 면 1.6배) |
| 방어력 | 받는 피해 -8% (Lv 5 면 40% 덜 아픔) |
| 속도 | 걷기 +7%, 대시 쿨다운 -8% |
| 로봇 볼트 | Lv 1: 가까운 적(날아다니는 몬스터, 보스도)에게 3초마다 레이저 8. 레벨마다 더 자주, 더 세게. Lv 3 부터 2마리, Lv 5 는 3마리. Lv 4 부터 12초마다 체력 10 수리, Lv 5 는 15초마다 공격 한 번을 막는 볼트 방패 |

- 한 번에 여러 레벨이 오르면 카드를 그 수만큼 차례로 고릅니다.
- 보스를 쓰러뜨리는 슬로모션이나 승리 화면, 궁극기 중에는 카드를 띄우지 않고 기다렸다가, 다음 스테이지를 시작할 때 보여 줍니다. 고르지 않은 카드는 저장돼서 다음에 게임을 할 때 나옵니다.
- 카드가 생기기 전에 저장한 게임은 지금까지 오른 레벨만큼 카드를 공짜로 고릅니다. (예: 레벨 6 이면 5장)
- 숫자는 `balance.js` 의 `upgrades`, `robot`, `powers` 에 있습니다.

**헤엄치기 (스테이지 6):** 점프를 누르면 위로 헤엄치고, 꾹 누르고 있으면 계속 올라갑니다. 떼면 천천히 가라앉습니다. 옆으로는 조금 느리고 물에서 미끄러지듯 멈춥니다. 대시는 짧은 헤엄 돌진(점프를 누르고 있으면 비스듬히 위로). 숫자는 `balance.js` 의 `swim`.

몬스터는 펀치에 맞으면 조금 밀리고, 최대 충전 펀치를 맞으면 쓰러집니다. 밀리는 정도는 `balance.js` 의 `monster.knockbackScale`, 주인공이 맞고 밀리는 정도는 `monster.heroKnockback` 으로 바꿀 수 있습니다.

## 아이들이 직접 고쳐 볼 수 있는 파일

| 파일 | 바꿀 수 있는 것 |
|---|---|
| `src/config/balance.js` | 체력, 속도, 점프 높이, 펀치 세기, 보스 공격 속도 같은 모든 숫자 |
| `src/stage/stage1.js` ~ `stage5.js` | 몬스터 위치와 종류, 발판, 보물, 안내판 글, 로봇 대사, 보스 체력과 공격 목록, 색 |
| `src/config/art.js` | 직접 그린 그림(PNG)으로 바꾸기 |

숫자를 이상하게 넣어도(음수, 글자 등) 게임은 멈추지 않고 고쳐서 씁니다. 무엇을 고쳤는지는 브라우저 개발자 도구 콘솔에 나옵니다.
스테이지 파일 고치는 규칙은 [src/stage/README.md](src/stage/README.md)에 있고, `npm test` 를 돌리면 규칙을 어겼는지(몬스터가 문 뒤에 있다, 발판이 너무 높다 등) 알려 줍니다.

### 내 그림으로 바꾸기

1. 그림을 PNG로 저장해 `public/art/` 폴더에 넣습니다 (예: `public/art/player.png`).
2. `src/config/art.js` 에서 해당 줄 앞의 `//` 를 지웁니다.
3. 그림 크기는 자동으로 맞춰집니다. 주인공과 몬스터는 오른쪽을 보는 모습으로 그려 주세요.

그림은 한꺼번에 받지 않고 필요할 때 받습니다(`src/logic/stageArt.js`). 처음 접속할 때는 아이콘, 하트, 깃발, 상자 같은 작은 그림만 받아서 1MB 정도입니다. 스테이지에 들어갈 때 그 스테이지의 배경, 몬스터, 보스 그림을 받고, 한 번 받은 그림은 게임을 켜 둔 동안 다시 받지 않습니다. 도감과 보스 러시는 열 때 거기서 보여 주는 그림을 받습니다. 받는 동안 화면 가운데에 "그림 받는 중"이 나옵니다. 새 그림을 `art.js` 에 넣으면 이름 규칙(몬스터 도감 이름, 보스는 `_<스테이지 번호>` 로 끝나는 이름)으로 알아서 그 스테이지에서 받습니다. 처음부터 받아야 하는 그림이면 `BOOT_ART` 에 이름을 넣으세요. `npm test` 가 빠뜨린 그림이 없는지 확인합니다.


### 스테이지 배경 그림 넣기

스테이지 파일의 `theme` 에 적습니다. 예: 스테이지 3 용암 지대

```js
bgImage: { key: 'lava_bg', file: 'lava_bg.jpg' },       // 걸어가는 동안 천천히 흘러가는 배경 (가로로 긴 그림이 좋아요)
arenaImage: { key: 'lava_arena', file: 'lava_arena.jpg' }, // 보스 구역에 들어서면 서서히 나타나는 배경
```

그림은 `public/art/` 에 넣고, 크면 JPG 로 줄여 주세요(높이 720 정도). 그림 맨 아래 60 정도는 땅에 가려집니다.

공중 발판 그림: `platformImage: { key, file, left, right, surface, scale }` (양 끝 `left`, `right` 픽셀은 그대로 두고 가운데만 늘립니다).

바닥 그림도 같은 곳에 적습니다: `groundImage: { key: 'lava_ground', file: 'lava_ground.png', surface: 30 }` (`surface` 는 그림 위에서 걸어 다니는 윗면까지 높이).
AI 바닥 그림은 `python3 tools/make_ground_tile.py 원본.png public/art/결과.png` 로 체크무늬를 지우고, 높이를 맞추고, 좌우 이음새를 없앤 타일로 만들 수 있습니다.

### 움직이는 그림(스프라이트 시트) 넣기

여러 장면을 한 장에 칸으로 나눠 그린 그림도 쓸 수 있습니다. 예: 아스트라노바X 8장 날갯짓.

```js
dragon_3: { file: 'astranova.png', cols: 4, rows: 2, frameRate: 8 },
```

- `cols`, `rows`: 가로, 세로 칸 수. 왼쪽 위 칸부터 0, 1, 2 ... 순서로 재생합니다.
- `frameRate`: 1초에 몇 장. 계속 반복합니다.
- 그림이 오른쪽을 보고 있으면 `faces: 'right'` 를 더 적습니다. 예: 포레스트 와처 `watcher_2: { file: 'forest_watcher.png', cols: 4, rows: 2, frameRate: 8, faces: 'right' }`
- 배경은 진짜 투명이어야 합니다. AI가 체크무늬를 그림에 그려 넣었다면 `python3 tools/remove_checker_bg.py 원본.png public/art/결과.png` 로 지울 수 있습니다.

## 컴퓨터에서 실행하기

[Node.js](https://nodejs.org/) 22 이상이 필요합니다.

```bash
npm install     # 처음 한 번
npm run dev     # 개발 서버 시작 → 터미널에 나온 주소(http://localhost:5173)를 브라우저로 열기
```

`npm run dev` 를 켜 둔 채 파일을 저장하면 브라우저가 알아서 새로고침됩니다.

그 밖의 명령:

```bash
npm test        # 자동 테스트 (충전 피해, 레벨, 저장, 보스 패턴, 스테이지 파일 검사 등)
npm run build   # 인터넷에 올릴 파일을 dist/ 에 만들기
npm run preview # 만든 파일을 내 컴퓨터에서 미리 보기
```

주소 끝에 붙이는 옵션:

- `?debug` : 충돌 상자를 보여 줍니다.
- `?timer` : 화면이 없는 브라우저에서 자동 확인할 때 씁니다.
- `?all` : 잠긴 스테이지까지 모두 골라서 해 볼 수 있습니다. (테스트용, 저장은 바뀌지 않음)
- `?duo` : 함께하기 시험용으로 친구 주인공(2P, 번개 사수)이 같이 나옵니다. 2P는 브라우저 콘솔에서 `window.__p2 = { right: true }` 처럼 키를 넣어 움직입니다. (인터넷 함께하기가 생기면 친구가 누른 키가 여기로 들어옵니다)

## 인터넷에 올리기 (Render)

이 레포에는 Render 설정 파일(`render.yaml`)이 들어 있습니다. Render 대시보드에서
**New → Blueprint** 를 고르고 이 레포를 선택하면 무료 정적 사이트로 올라갑니다.
그다음부터는 `main` 브랜치에 push 할 때마다 자동으로 다시 배포됩니다.
