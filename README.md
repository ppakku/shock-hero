# 쇼크 히어로: 몬스터 브레이커

도시를 부수는 돌연변이 괴물과 싸우는 2D 액션 게임입니다. 브라우저에서 바로 플레이할 수 있습니다.
설계 문서는 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md), 만들면서 정한 것들은 [docs/DECISIONS.md](docs/DECISIONS.md)에 있습니다.

## 조작법

| 동작 | 키 |
|---|---|
| 이동 | A / D 또는 ← → |
| 점프 | Space (W, ↑ 도 됨). 짧게 누르면 낮게, 길게 누르면 높게 |
| 펀치 | J 또는 마우스 왼쪽 |
| 충전 펀치 | J 를 꾹 눌렀다가 떼기. 파란 링이 다 차면 MAX, 파란 에너지탄이 앞으로 날아감 |
| 어퍼컷 (위쪽 공격) | W 나 ↑ 를 누른 채 펀치. 머리 위 하늘의 적을 때림. 충전하면 에너지탄이 위로 (걸으면서 쏘면 대각선 위로) |
| 궁극기 | L. 적을 때리면 파란 궁극기 게이지가 참. 꽉 차면 뛰어올라 땅을 찍고, 화면 안의 모든 적에게 큰 피해 |
| 대시 | K 또는 Shift. 대시 중에는 공격을 맞지 않음 |
| 일시정지 | Esc (일시정지 화면에서 H: 화면 흔들림, M: 소리, T: 타이틀로) |

## 시작 전에 고르는 것 (타이틀 화면)

스테이지 카드 아래 버튼 줄에서 고릅니다. ↓ 키로 버튼 줄로 내려가 ← → 로 고르고 Enter 를 누르거나, 마우스로 눌러도 됩니다.

- **난이도:** 쉬움, 보통, 어려움.
  - 쉬움: 몬스터 수가 적고, 특수 몬스터 일부가 초록 몬스터로 바뀝니다. 몬스터가 약하고 공격 신호가 깁니다. 보스는 체력이 적고 느립니다.
  - 어려움: 몬스터가 더 많고 다양하며 빠르고 아픕니다. 보스는 더 튼튼하고 빠르며, 공격 두 개를 동시에 겹쳐 쓰는 일이 많습니다.
- **조작:** 기본(WASD + J K L) 또는 방향키 + A S D(A 펀치, S 대시, D 궁극기).
- **레벨 초기화:** 레벨, 경험치, 보물, 스테이지 기록을 모두 지우고 처음부터 다시 쌓습니다. 한 번 더 확인한 뒤 지웁니다. 난이도, 조작, 소리 설정은 남습니다.

## 게임 흐름

스테이지는 5개입니다. 하나를 깨면 다음 스테이지가 열리고, 타이틀에서 ← → 나 숫자 키로 열린 스테이지를 고를 수 있습니다.

| 스테이지 | 이름 | 새로 나오는 것 | 보스 |
|---|---|---|---|
| 1 | 파괴된 도시 | 초록 몬스터, 조작 배우기 | 다중 팔 돌연변이 (팔 2개, 주먹 발사, 빨아들이기, 분노 모드) |
| 2 | 독 숲 | 빨강 날쌘돌이, 프로스 (아들 디자인 말벌) | 포레스트 와처 (아들 디자인) |
| 3 | 용암 지대 | 파랑 뚱보, 청록 침뱉기 | 아스트라노바X (아들 디자인) |
| 4 | 얼음 산 | 보라 뜀뛰기, 회색 방패병 | 얼음 돌연변이 (하늘을 나는 박쥐 용, 날개 2개와 얼음 심장) |
| 5 | 괴물 성 | 모든 몬스터 | 킹 돌연변이 (왕좌의 왕, 부하 소환, 팔을 다 부수면 일어나서 뛰어다님) |

1. 몬스터를 **모두** 잡아야 빨간 보스 문이 열립니다. 화면 위에 "남은 몬스터" 수가 나옵니다.
2. 몬스터는 가끔 하트를 떨어뜨립니다. 먹으면 체력이 찹니다.
3. 스테이지마다 보물 상자가 3개씩(모두 15개) 숨어 있습니다. 먹으면 사라지고, 한 번 찾은 보물은 다시 나오지 않습니다.
4. 보스 문을 지나면 초록 깃발(체크포인트)에서 체력이 다 찹니다. 여기부터는 쓰러져도 보스 앞에서 다시 시작합니다.
5. 보스는 팔이 바닥에 박혀 있을 때("지금! 때려!")만 팔에 피해가 들어갑니다. 팔을 다 부수면 코어가 드러납니다.

몬스터 상대하는 법:

| 몬스터 | 하는 일 | 이기는 법 |
|---|---|---|
| 초록, 빨강, 파랑 | 빨갛게 깜빡이고 "!" 가 뜬 뒤 달려듦 | 대시로 피하고, 멍하게 쉴 때 때리기 |
| 보라 뜀뛰기 | 점프해서 덮침 | 대시로 밑으로 빠져나가기 |
| 프로스 (말벌) | 하늘을 날며 옆 위쪽에서 맹독을 비스듬히 쏨. 배를 앞으로 구부리고 보라색으로 빛나며 점선과 보라 타원으로 떨어질 곳을 먼저 보여 줌. 독이 떨어진 곳에 독구름이 1.5초 남아서 안에 있으면 체력이 조금씩 깎임 | 점선이 하얗게 깜빡이면 그 자리에서 비키기. 독구름은 피하거나 대시로 지나가기(대시 중엔 안 깎임). 독을 쏜 뒤 낮게 내려와 쉴 때 점프 펀치나 위쪽 공격 |
| 청록 침뱉기 | 거리를 두고 느린 침을 뱉음. 볼이 부풀고 초록 점선이 먼저 보임 | 점프로 넘거나 대시로 뚫기. 가까이 붙으면 도망가니 쫓아가서 때리기 |
| 회색 방패병 | 앞쪽 방패로 기본 펀치를 막음("막힘!") | 충전 펀치로 방패 깨기(3초 뒤 다시 듦), 아니면 뒤로 돌아가서 때리기. 몸을 천천히 돌림 |

몬스터는 펀치에 맞으면 조금 밀리고, 최대 충전 펀치를 맞으면 쓰러집니다. 밀리는 정도는 `balance.js` 의 `monster.knockbackScale`, 주인공이 맞고 밀리는 정도는 `monster.heroKnockback` 으로 바꿀 수 있습니다.

보스 공격 피하는 법:

| 공격 | 신호 | 피하는 법 |
|---|---|---|
| 내려찍기, 연속 내려찍기 | 빨간 기둥 | 옆으로 비키기. 찍은 팔을 때릴 기회 |
| 두 팔 동시 | 빨간 기둥 2개 | 기둥 사이 빈 곳으로 |
| 바닥 쓸기 | 넓은 빨간 칸 | 점프로 못 넘음, 대시로 통과 |
| 돌 떨구기 | 바닥의 검은 그림자 | 그림자 밖으로 |
| 땅 울림 충격파 | 바닥의 낮은 빨간 띠, "점프!" | 점프로 넘기 |
| 독침 | 보스 입이 초록으로 번쩍 | 떨어질 자리(초록 원)를 피해 계속 움직이기 |
| 주먹 발사 | 팔을 뒤로 당기고 빨간 띠와 화살표, "낮다! 점프!" 또는 "높다! 가만히!" | 낮으면 점프, 높으면 가만히 서 있기. 벽에 박힌 주먹을 때릴 기회 |
| 빨아들이기 | 입이 열리고 하얀 소용돌이 선 | 반대쪽으로 계속 달리기 (충전하면 느려져서 끌려감) |
| 분노 모드 | 보스가 빨개지고 "분노!" | 코어 체력이 절반 아래. 공격 두 개를 쉬지 않고 이어서 함 |
| 고드름 비 (얼음) | 바닥의 그림자 | 그림자 밖으로 |
| 급강하 (얼음) | 점선 길과 빨간 칸 | 대시로 뚫고 지나가기. 끝나고 낮게 뜨면 점프 펀치 |
| 얼음 숨결 (얼음) | 바닥의 파란 띠, "점프로 넘어!" | 점프로 넘기 |
| 지쳐서 내려앉기 (얼음) | "지쳤다! 지금 때려!" | 날개를 마구 때릴 기회 |
| 부하 소환 (킹) | 보라색 구멍 | 나오는 몬스터를 잡거나 피하기 (최대 2마리) |
| 뛰어 내려찍기 (킹, 얼음) | 그림자와 빨간 칸 | 그림자 밖으로. 킹은 내려앉으면 충격파가 양쪽으로 가니 점프 |
| 돌진 (킹) | 넓은 빨간 칸, "돌진! 대시로 통과!" | 대시로 뚫고 지나가기 |
| 와처: 긴 팔 할퀴기 | 가슴 높이 빨간 줄 | 점프로 넘거나 대시로 통과. 땅에 박힌 팔을 때릴 기회 |
| 와처: 땅속에서 튀어나오기 | 초록으로 갈라지는 땅과 빨간 칸 | 빨간 칸 밖으로 |
| 와처: 독 점액 | 입이 초록으로 번쩍, 초록 원 | 초록 원을 피하기. 남은 독 웅덩이는 밟지 않기 |
| 와처: 덩굴 붙잡기 | 바닥의 잎사귀 표시 | 표시에서 비키기. 잡히면 대시로 빠져나오기 |
| 와처: 벽 타고 천장으로 | 바닥의 초록 원 여러 개 | 천장에서 떨어지는 독 방울 자리 피하기 |
| 용: 불 뿜기 | 입 앞부터 벽까지 낮은 빨간 띠 | 땅을 훑는 불길을 점프로 넘기 |
| 용: 날개 바람 | 벽 쪽 바닥이 주황으로 빛남 | 용 쪽으로 계속 걸어서 버티기 (벽 쪽에서 불기둥) |
| 용: 꼬리 휘두르기 | 등 뒤 낮은 빨간 칸 | 점프로 넘거나 대시로 통과. 떨어진 꼬리를 때릴 기회 |
| 용: 날아올라 불 폭격 | 빨간 동그라미와 내려앉을 빨간 칸 | 동그라미와 빨간 칸 밖으로, 내려앉은 뒤 충격파는 점프 |
| 용: 용암 불기둥 | 바닥이 주황으로 빛남 | 빛나지 않는 곳으로 |

레벨, 경험치, 보물, 스테이지별 최고 기록은 브라우저에 자동 저장됩니다. (같은 컴퓨터, 같은 브라우저에서만 이어집니다)

## 아이들이 직접 고쳐 볼 수 있는 파일

| 파일 | 바꿀 수 있는 것 |
|---|---|
| `src/config/balance.js` | 체력, 속도, 점프 높이, 펀치 세기, 보스 공격 속도 같은 모든 숫자 |
| `src/stage/stage1.js` ~ `stage5.js` | 몬스터 위치와 종류, 발판, 보물, 안내판 글, 로봇 대사, 보스 체력과 공격 목록, 색 |
| `src/config/art.js` | 직접 그린 그림(PNG)으로 바꾸기 |

숫자를 이상하게 넣어도(음수, 글자 등) 게임은 멈추지 않고 고쳐서 씁니다. 무엇을 고쳤는지는 브라우저 개발자 도구 콘솔에 나옵니다.
스테이지 파일 고치는 규칙은 [src/stage/README.md](src/stage/README.md)에 있고, `npm test` 를 돌리면 규칙을 어겼는지(몬스터가 문 뒤에 있다, 발판이 너무 높다 등) 알려 줍니다.

### 내 그림으로 바꾸기

1. 그림을 PNG로 저장해 `public/art/` 폴더에 넣습니다 (예: `public/art/player.png`).
2. `src/config/art.js` 에서 해당 줄 앞의 `//` 를 지웁니다.
3. 그림 크기는 자동으로 맞춰집니다. 주인공과 몬스터는 오른쪽을 보는 모습으로 그려 주세요.

## 컴퓨터에서 실행하기

[Node.js](https://nodejs.org/) 22 이상이 필요합니다.

```bash
npm install     # 처음 한 번
npm run dev     # 개발 서버 시작 → 터미널에 나온 주소(http://localhost:5173)를 브라우저로 열기
```

`npm run dev` 를 켜 둔 채 파일을 저장하면 브라우저가 알아서 새로고침됩니다.

그 밖의 명령:

```bash
npm test        # 자동 테스트 (충전 피해, 레벨, 저장, 보스 패턴, 스테이지 파일 검사 등)
npm run build   # 인터넷에 올릴 파일을 dist/ 에 만들기
npm run preview # 만든 파일을 내 컴퓨터에서 미리 보기
```

주소 끝에 붙이는 옵션:

- `?debug` : 충돌 상자를 보여 줍니다.
- `?timer` : 화면이 없는 브라우저에서 자동 확인할 때 씁니다.
- `?all` : 잠긴 스테이지까지 모두 골라서 해 볼 수 있습니다. (테스트용, 저장은 바뀌지 않음)

## 인터넷에 올리기 (Render)

이 레포에는 Render 설정 파일(`render.yaml`)이 들어 있습니다. Render 대시보드에서
**New → Blueprint** 를 고르고 이 레포를 선택하면 무료 정적 사이트로 올라갑니다.
그다음부터는 `main` 브랜치에 push 할 때마다 자동으로 다시 배포됩니다.

## 폴더 구조

```
src/
  config/      balance.js(숫자), art.js(그림 바꾸기)
  stage/       stage1.js ~ stage5.js(맵 배치와 보스), index.js(순서)
  logic/       화면과 상관없는 계산 (테스트 대상)
  player/      주인공, 로봇 조수
  enemies/     몬스터 7종류 (Monster.js 기본, Fros.js 프로스, Spitter.js 침뱉기, ShieldMonster.js 방패병)
  boss/        돌연변이 보스 (스테이지마다 설정이 다름)
  scenes/      타이틀, 게임, HUD(체력바 등)
  fx/ audio/   임시 그림, 효과, 효과음
tests/         자동 테스트
```
