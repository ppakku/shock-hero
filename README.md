# 쇼크 히어로: 몬스터 브레이커

도시를 부수는 돌연변이 괴물과 싸우는 2D 액션 게임입니다. 브라우저에서 바로 플레이할 수 있습니다.
설계 문서는 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md), 만들면서 정한 것들은 [docs/DECISIONS.md](docs/DECISIONS.md)에 있습니다.

## 조작법

| 동작 | 키 |
|---|---|
| 이동 | A / D 또는 ← → |
| 점프 | Space (W, ↑ 도 됨). 짧게 누르면 낮게, 길게 누르면 높게 |
| 펀치 | J 또는 마우스 왼쪽 |
| 충전 펀치 | J 를 꾹 눌렀다가 떼기. 파란 링이 다 차면 MAX, 파란 에너지탄이 앞으로 날아감 |
| 어퍼컷 (위쪽 공격) | W 나 ↑ 를 누른 채 펀치. 머리 위 하늘의 적을 때림. 충전하면 에너지탄이 위로 (걸으면서 쏘면 대각선 위로) |
| 궁극기 | L. 적을 때리면 파란 궁극기 게이지가 참. 꽉 차면 뛰어올라 땅을 찍고, 화면 안의 모든 적에게 큰 피해 |
| 대시 | K 또는 Shift. 대시 중에는 공격을 맞지 않음 |
| 일시정지 | Esc (일시정지 화면에서 H: 화면 흔들림, M: 소리, T: 타이틀로) |

### 태블릿 (키보드 없음)

손가락 화면인 기기로 열면 화면 위에 조작이 나옵니다. 왼쪽 절반은 조이스틱입니다: 아무 데나 엄지를 대면 그 자리가 가운데가 되고, 끄는 방향으로 걷습니다(위로 민 채 펀치하면 어퍼컷). 오른쪽 아래는 점프, 펀치(꾹 눌렀다 떼면 충전 펀치), 대시, 궁극기 버튼, 오른쪽 위 II 는 일시정지입니다. 버튼은 게임이 잘 보이게 흐릿하고 누르는 동안만 또렷해집니다. 물속에서는 점프 버튼을 꾹 눌러 헤엄칩니다. 타이틀 카드는 한 번 누르면 고르고 한 번 더 누르면 시작합니다. 결과 화면과 일시정지 화면에도 누르는 버튼이 나옵니다. 버튼 위치와 크기는 `src/ui/touch.js` 의 `TOUCH_BUTTONS`, 조이스틱은 `STICK` 숫자로 바꿉니다. 컴퓨터에서 확인하려면 주소 끝에 `?touch` 를 붙입니다. 아이패드는 사파리 공유 메뉴에서 "홈 화면에 추가" 하면 주소창 없이 꽉 찬 화면으로 열립니다.

## 시작 전에 고르는 것 (타이틀 화면)

타이틀 화면은 흑백 만화 그림체입니다 (docs/title_design.png 오른쪽 그림). 회색 연기 낀 불타는 도시, 옥상 위에서 망토를 휘날리는 주인공, 철판에 적힌 조작법, 사진처럼 핀으로 꽂은 스테이지 카드가 나옵니다. 그림은 모두 코드로 그립니다 (src/ui/titleArt.js). 스테이지 파일에 `titlePhoto: 'water'` 처럼 적으면 카드 사진 장면(city, forest, lava, ice, castle, water)을 고를 수 있습니다.

스테이지 카드 아래 버튼 줄에서 고릅니다. ↓ 키로 버튼 줄로 내려가 ← → 로 고르고 Enter 를 누르거나, 마우스로 눌러도 됩니다.

- **난이도:** 쉬움, 보통, 어려움.
  - 쉬움: 몬스터 수가 적고, 특수 몬스터 일부가 초록 몬스터로 바뀝니다. 몬스터가 약하고 공격 신호가 깁니다. 보스는 체력이 적고 느립니다.
  - 어려움: 몬스터가 더 많고 다양하며 빠르고 아픕니다. 보스는 더 튼튼하고 빠르며, 공격 두 개를 동시에 겹쳐 쓰는 일이 많습니다.
- **조작:** 기본(WASD + J K L) 또는 방향키 + A S D(A 펀치, S 대시, D 궁극기).
- **레벨 초기화:** 레벨, 경험치, 레벨 업 카드, 보물, 스테이지 기록을 모두 지우고 처음부터 다시 쌓습니다. 한 번 더 확인한 뒤 지웁니다. 난이도, 조작, 소리 설정은 남습니다.

## 게임 흐름

스테이지는 6개입니다. 하나를 깨면 다음 스테이지가 열리고, 타이틀에서 ← → 나 숫자 키로 열린 스테이지를 고를 수 있습니다.

| 스테이지 | 이름 | 새로 나오는 것 | 보스 |
|---|---|---|---|
| 1 | 파괴된 도시 | 초록 몬스터, 조작 배우기 | 파쇄자 (아들 그림: 녹슨 파쇄 기계, 쇠팔 2개, 주먹 발사, 빨아들이기, 분노 모드) |
| 2 | 독 숲 | 빨강 날쌘돌이, 프로스 (아들 디자인 말벌) | 포레스트 와처 (아들 디자인) |
| 3 | 용암 지대 | 파랑 뚱보, 청록 침뱉기 | 아스트라노바X (아들 디자인) |
| 4 | 얼음 산 | 보라 뜀뛰기, 회색 방패병 | 혹한의 아스트라 (아들 디자인, 하늘을 나는 얼음 용, 날개 2개와 얼음 심장, 냉기 브레스와 빙천지락) |
| 5 | 괴물 성 | 모든 몬스터 | 킹 돌연변이 (왕좌의 왕, 부하 소환, 팔을 다 부수면 일어나서 뛰어다님) |
| 6 | 수중 던전 (마지막, 헤엄치기) | 골드해파리 GX (아들 디자인), 가시복어, 이빨 피라냐, 집게 꽃게 | 심해 아귀왕 (임시 디자인: 초롱불과 큰 턱, 돌진, 거품 폭탄, 소용돌이, 먹물, 꼬리 휩쓸기) |

1. 몬스터를 **모두** 잡아야 빨간 보스 문이 열립니다. 화면 위에 "남은 몬스터" 수가 나옵니다.
2. 몬스터는 가끔 하트를 떨어뜨립니다. 먹으면 체력이 찹니다.
3. 스테이지마다 보물 상자가 3개씩(모두 18개) 숨어 있습니다. 먹으면 사라지고, 한 번 찾은 보물은 다시 나오지 않습니다. 보물은 경험치 대신 **잠깐 동안 특별한 힘**을 줍니다(아래 표).
4. 보스 문을 지나면 초록 깃발(체크포인트)에서 체력이 다 찹니다. 여기부터는 쓰러져도 보스 앞에서 다시 시작합니다.
5. 보스는 팔이 바닥에 박혀 있을 때("지금! 때려!")만 팔에 피해가 들어갑니다. 팔을 다 부수면 코어가 드러납니다.
6. 경험치는 몬스터와 보스(팔, 날개, 마지막 일격)를 쓰러뜨려야 얻습니다. 레벨이 오르면 최대 체력이 10 늘고, 게임이 멈추면서 **레벨 업 카드**를 한 장 고릅니다.

보물 상자의 특별한 힘 (화면 가운데 커다란 이름, 왼쪽 위 아이콘에 남은 초가 나옵니다. 끝나기 전에 깜빡여요):

| 힘 | 시간 | 하는 일 | 주인공 모습 |
|---|---|---|---|
| 번개 신발 | 12초 | 걷기 1.5배, 대시 쿨다운 절반 | 노란 잔상 |
| 강철 몸 | 20초 | 체력바 위에 방패 60. 피해를 방패가 먼저 받음 (다 깨지면 끝) | 은빛 방울, 체력바 위 은빛 줄 |
| 파워 장갑 | 12초 | 모든 공격 피해 1.6배 | 주먹이 빨갛게 이글이글 |
| 무적 별 | 6초 | 아무것도 안 아픔. 몸에 닿은 적이 다침 (0.25초마다 14) | 무지개 빛 |
| 에너지 연사 | 10초 | 펀치할 때마다 파란 에너지탄이 나감 (에너지탄 피해의 절반) | 주먹 둘레에 파란 공 |

스테이지 파일 보물에 `power: 'star'` 처럼 쓰면 그 힘이 나오고, 안 쓰면 아무거나 나옵니다. 같은 힘을 또 먹으면 시간이 처음부터 다시 갑니다.

레벨 업 카드 (← → 와 Enter, 숫자 1 ~ 4, 또는 마우스 클릭. 카드마다 최고 Lv 5):

| 카드 | 한 번 고를 때마다 |
|---|---|
| 공격력 | 모든 공격 +12% (Lv 5 면 1.6배) |
| 방어력 | 받는 피해 -8% (Lv 5 면 40% 덜 아픔) |
| 속도 | 걷기 +7%, 대시 쿨다운 -8% |
| 로봇 볼트 | Lv 1: 가까운 적(날아다니는 몬스터, 보스도)에게 3초마다 레이저 8. 레벨마다 더 자주, 더 세게. Lv 3 부터 2마리, Lv 5 는 3마리. Lv 4 부터 12초마다 체력 10 수리, Lv 5 는 15초마다 공격 한 번을 막는 볼트 방패 |

- 한 번에 여러 레벨이 오르면 카드를 그 수만큼 차례로 고릅니다.
- 보스를 쓰러뜨리는 슬로모션이나 승리 화면, 궁극기 중에는 카드를 띄우지 않고 기다렸다가, 다음 스테이지를 시작할 때 보여 줍니다. 고르지 않은 카드는 저장돼서 다음에 게임을 할 때 나옵니다.
- 카드가 생기기 전에 저장한 게임은 지금까지 오른 레벨만큼 카드를 공짜로 고릅니다. (예: 레벨 6 이면 5장)
- 숫자는 `balance.js` 의 `upgrades`, `robot`, `powers` 에 있습니다.

몬스터 상대하는 법:

| 몬스터 | 하는 일 | 이기는 법 |
|---|---|---|
| 초록, 빨강, 파랑 | 빨갛게 깜빡이고 "!" 가 뜬 뒤 달려듦 | 대시로 피하고, 멍하게 쉴 때 때리기 |
| 보라 뜀뛰기 | 점프해서 덮침 | 대시로 밑으로 빠져나가기 |
| 프로스 (말벌) | 하늘을 날며 옆 위쪽에서 맹독을 비스듬히 쏨. 배를 앞으로 구부리고 보라색으로 빛나며 점선과 보라 타원으로 떨어질 곳을 먼저 보여 줌. 독이 떨어진 곳에 독구름이 1.5초 남아서 안에 있으면 체력이 조금씩 깎임 | 점선이 하얗게 깜빡이면 그 자리에서 비키기. 독구름은 피하거나 대시로 지나가기(대시 중엔 안 깎임). 독을 쏜 뒤 낮게 내려와 쉴 때 점프 펀치나 위쪽 공격 |
| 청록 침뱉기 | 거리를 두고 느린 침을 뱉음. 볼이 부풀고 초록 점선이 먼저 보임 | 점프로 넘거나 대시로 뚫기. 가까이 붙으면 도망가니 쫓아가서 때리기 |
| 회색 방패병 | 앞쪽 방패로 기본 펀치를 막음("막힘!") | 충전 펀치로 방패 깨기(3초 뒤 다시 듦), 아니면 뒤로 돌아가서 때리기. 몸을 천천히 돌림 |
| 골드해파리 GX (수중) | 둥둥 떠다니며 보라 점선 뒤 전기 독을 쏨. 가까이 가면 빛나는 공으로 순간 경화("팅!") | 점선 위나 아래로 헤엄쳐 피하기. 경화하면 충전 펀치(반 이상 충전)로 깨거나, 풀리고 지쳐 가라앉을 때 때리기 |
| 가시복어 (수중) | 가까이 가면 부르르 떨다가 가시 공으로 부풂. 닿으면 아픔 | 부풀었을 때 맨손 펀치는 내가 "따끔!". 피해 있다가 바람이 빠져 빙글빙글 돌 때 때리기. 에너지탄과 충전 펀치는 통함 |
| 이빨 피라냐 (수중) | 떼로 다니며 빨간 점선을 따라 일직선 돌진 | 점선 밖으로 헤엄치거나 대시. 돌진 뒤 숨 고를 때 때리기 |
| 집게 꽃게 (수중) | 바닥을 옆걸음으로 다니다가 빨개지면 집게로 꽉 | 초록 몬스터처럼: 위로 헤엄쳐 피하고 쉴 때 때리기 |

**헤엄치기 (스테이지 6):** 점프를 누르면 위로 헤엄치고, 꾹 누르고 있으면 계속 올라갑니다. 떼면 천천히 가라앉습니다. 옆으로는 조금 느리고 물에서 미끄러지듯 멈춥니다. 대시는 짧은 헤엄 돌진(점프를 누르고 있으면 비스듬히 위로). 숫자는 `balance.js` 의 `swim`.

몬스터는 펀치에 맞으면 조금 밀리고, 최대 충전 펀치를 맞으면 쓰러집니다. 밀리는 정도는 `balance.js` 의 `monster.knockbackScale`, 주인공이 맞고 밀리는 정도는 `monster.heroKnockback` 으로 바꿀 수 있습니다.

보스 공격 피하는 법:

| 공격 | 신호 | 피하는 법 |
|---|---|---|
| 내려찍기, 연속 내려찍기 | 빨간 기둥 | 옆으로 비키기. 찍은 팔을 때릴 기회 |
| 두 팔 동시 | 빨간 기둥 2개 | 기둥 사이 빈 곳으로 |
| 바닥 쓸기 | 넓은 빨간 칸 | 점프로 못 넘음, 대시로 통과 |
| 돌 떨구기 | 바닥의 검은 그림자 | 그림자 밖으로 |
| 땅 울림 충격파 | 바닥의 낮은 빨간 띠, "점프!" | 점프로 넘기 |
| 독침 | 보스 입이 초록으로 번쩍 | 떨어질 자리(초록 원)를 피해 계속 움직이기 |
| 주먹 발사 | 팔을 뒤로 당기고 빨간 띠와 화살표, "낮다! 점프!" 또는 "높다! 가만히!" | 낮으면 점프, 높으면 가만히 서 있기. 벽에 박힌 주먹을 때릴 기회 |
| 빨아들이기 | 입이 열리고 하얀 소용돌이 선 | 반대쪽으로 계속 달리기 (충전하면 느려져서 끌려감) |
| 분노 모드 | 보스가 빨개지고 "분노!" | 코어 체력이 절반 아래. 공격 두 개를 쉬지 않고 이어서 함 |
| 고드름 비 (아스트라) | 바닥의 그림자 | 그림자 밖으로 |
| 급강하 (아스트라) | 점선 길과 빨간 칸 | 대시로 뚫고 지나가기. 끝나고 낮게 뜨면 점프 펀치나 위쪽 공격 |
| 냉기 브레스 (아스트라) | 입이 하얗게 빛나고 파란 부채꼴과 바닥 띠, "냉기 브레스!" | 부채꼴 밖으로. 아스트라 밑이나 뒤("안전")가 제일 안전. 부채꼴 끝에서 낮은 서리가 쌓였다가 바닥을 달려오니 점프로 넘거나 대시로 뚫기 |
| 빙천지락 (아스트라) | 하늘로 솟아 포효, 바닥 여러 곳이 빛나고 얼음 조각이 꽂힘 | 빛나지 않는 틈에 서 있기. 가시가 두 묶음으로 번갈아 솟으니 다음 빛이 오면 옆 틈으로 옮기기 (분노하면 한 번 더) |
| 지쳐서 내려앉기 (아스트라) | "지쳤다! 지금 때려!" | 날개를 마구 때릴 기회 |

## 아이들이 직접 고쳐 볼 수 있는 파일

| 파일 | 바꿀 수 있는 것 |
|---|---|
| `src/config/balance.js` | 체력, 속도, 점프 높이, 펀치 세기, 보스 공격 속도 같은 모든 숫자 |
| `src/stage/stage1.js` ~ `stage5.js` | 몬스터 위치와 종류, 발판, 보물, 안내판 글, 로봇 대사, 보스 체력과 공격 목록, 색 |
| `src/config/art.js` | 직접 그린 그림(PNG)으로 바꾸기 |

숫자를 이상하게 넣어도(음수, 글자 등) 게임은 멈추지 않고 고쳐서 씁니다. 무엇을 고쳤는지는 브라우저 개발자 도구 콘솔에 나옵니다.
스테이지 파일 고치는 규칙은 [src/stage/README.md](src/stage/README.md)에 있고, `npm test` 를 돌리면 규칙을 어겼는지(몬스터가 문 뒤에 있다, 발판이 너무 높다 등) 알려 줍니다.

### 내 그림으로 바꾸기

1. 그림을 PNG로 저장해 `public/art/` 폴더에 넣습니다 (예: `public/art/player.png`).
2. `src/config/art.js` 에서 해당 줄 앞의 `//` 를 지웁니다.
3. 그림 크기는 자동으로 맞춰집니다. 주인공과 몬스터는 오른쪽을 보는 모습으로 그려 주세요.


### 스테이지 배경 그림 넣기

스테이지 파일의 `theme` 에 적습니다. 예: 스테이지 3 용암 지대

```js
bgImage: { key: 'lava_bg', file: 'lava_bg.jpg' },       // 걸어가는 동안 천천히 흘러가는 배경 (가로로 긴 그림이 좋아요)
arenaImage: { key: 'lava_arena', file: 'lava_arena.jpg' }, // 보스 구역에 들어서면 서서히 나타나는 배경
```

그림은 `public/art/` 에 넣고, 크면 JPG 로 줄여 주세요(높이 720 정도). 그림 맨 아래 60 정도는 땅에 가려집니다.

바닥 그림도 같은 곳에 적습니다: `groundImage: { key: 'lava_ground', file: 'lava_ground.png', surface: 30 }` (`surface` 는 그림 위에서 걸어 다니는 윗면까지 높이).
AI 바닥 그림은 `python3 tools/make_ground_tile.py 원본.png public/art/결과.png` 로 체크무늬를 지우고, 높이를 맞추고, 좌우 이음새를 없앤 타일로 만들 수 있습니다.

### 움직이는 그림(스프라이트 시트) 넣기

여러 장면을 한 장에 칸으로 나눠 그린 그림도 쓸 수 있습니다. 예: 아스트라노바X 8장 날갯짓.

```js
dragon_3: { file: 'astranova.png', cols: 4, rows: 2, frameRate: 8 },
```

- `cols`, `rows`: 가로, 세로 칸 수. 왼쪽 위 칸부터 0, 1, 2 ... 순서로 재생합니다.
- `frameRate`: 1초에 몇 장. 계속 반복합니다.
- 그림이 오른쪽을 보고 있으면 `faces: 'right'` 를 더 적습니다. 예: 포레스트 와처 `watcher_2: { file: 'forest_watcher.png', cols: 4, rows: 2, frameRate: 8, faces: 'right' }`
- 배경은 진짜 투명이어야 합니다. AI가 체크무늬를 그림에 그려 넣었다면 `python3 tools/remove_checker_bg.py 원본.png public/art/결과.png` 로 지울 수 있습니다.

## 컴퓨터에서 실행하기

[Node.js](https://nodejs.org/) 22 이상이 필요합니다.

```bash
npm install     # 처음 한 번
npm run dev     # 개발 서버 시작 → 터미널에 나온 주소(http://localhost:5173)를 브라우저로 열기
```

`npm run dev` 를 켜 둔 채 파일을 저장하면 브라우저가 알아서 새로고침됩니다.

그 밖의 명령:

```bash
npm test        # 자동 테스트 (충전 피해, 레벨, 저장, 보스 패턴, 스테이지 파일 검사 등)
npm run build   # 인터넷에 올릴 파일을 dist/ 에 만들기
npm run preview # 만든 파일을 내 컴퓨터에서 미리 보기
```

주소 끝에 붙이는 옵션:

- `?debug` : 충돌 상자를 보여 줍니다.
- `?timer` : 화면이 없는 브라우저에서 자동 확인할 때 씁니다.
- `?all` : 잠긴 스테이지까지 모두 골라서 해 볼 수 있습니다. (테스트용, 저장은 바뀌지 않음)

## 인터넷에 올리기 (Render)

이 레포에는 Render 설정 파일(`render.yaml`)이 들어 있습니다. Render 대시보드에서
**New → Blueprint** 를 고르고 이 레포를 선택하면 무료 정적 사이트로 올라갑니다.
그다음부터는 `main` 브랜치에 push 할 때마다 자동으로 다시 배포됩니다.

```
src/
  config/      balance.js(숫자), art.js(그림 바꾸기)
  stage/       stage1.js ~ stage5.js(맵 배치와 보스), index.js(순서)
  logic/       화면과 상관없는 계산 (테스트 대상)
  player/      주인공, 로봇 조수
  enemies/     몬스터 7종류 (Monster.js 기본, Fros.js 프로스, Spitter.js 침뱉기, ShieldMonster.js 방패병)
  boss/        돌연변이 보스 (스테이지마다 설정이 다름)
  scenes/      타이틀, 게임, HUD(체력바 등)
  ui/          글자 도우미, 타이틀 화면 그림(titleArt.js)과 자리 계산(titleLayout.js)
  fx/ audio/   임시 그림, 효과, 효과음
tests/         자동 테스트
```
