# 스테이지 파일 고치는 법

- `x` 는 왼쪽에서부터 거리, `y` 는 위에서부터 거리입니다(아래로 갈수록 커짐).
- 땅 높이는 `groundY`(480). 점프로 올라갈 수 있는 높이는 약 130, 발판 사이 높이는 100 이하가 안전하고, 120 을 넘으면 못 올라갑니다.
- 몬스터는 모두 `gateX`(보스 문)보다 왼쪽에 둡니다. 몬스터를 다 잡아야 문이 열립니다.
- 몬스터 종류: `basic`(초록), `fast`(빨강 날쌘돌이), `tank`(파랑 뚱보), `jumper`(보라 뜀뛰기),
  `bomber`(노랑 폭탄벌레, 하늘을 남), `spitter`(청록 침뱉기), `shield`(회색 방패병).
  - 폭탄벌레는 `{ x: 2200, type: 'bomber' }` 처럼 쓰면 높이 290 에 뜹니다. `y` 를 적으면 250 ~ 340 사이에서만 납니다(그보다 높으면 못 때려서).
  - 지금은 폭탄벌레가 스테이지 2, 침뱉기가 3, 방패병이 4 부터 나오고 5 에는 전부 나옵니다. 새 몬스터가 처음 나오는 곳 앞에는 안내판이나 로봇 대사를 넣어 주세요.
- 보물 `id` 는 모든 스테이지에서 겹치면 안 됩니다.
- 안내판 글과 로봇 대사에 `{punch}`, `{dash}`, `{ult}`, `{up}`, `{move}`, `{jump}` 를 쓰면 고른 조작 방식의 키 이름으로 바뀝니다.
- 보스 공격 이름: `slam`(내려찍기), `multiSlam`(연속 내려찍기), `doubleSlam`(두 팔 동시), `sweep`(바닥 쓸기),
  `rocks`(돌 떨구기), `shockwave`(땅 울림, 점프로 넘기), `spit`(독침).
- `npm test` 를 돌리면 위 규칙을 어겼는지 자동으로 확인해 줍니다.
