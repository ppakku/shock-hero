# 스테이지 파일 고치는 법

- `x` 는 왼쪽에서부터 거리, `y` 는 위에서부터 거리입니다(아래로 갈수록 커짐).
- 땅 높이는 `groundY`(480). 점프로 올라갈 수 있는 높이는 약 130, 발판 사이 높이는 100 이하가 안전하고, 120 을 넘으면 못 올라갑니다.
  더블 점프(`balance.js` 의 `airJumps`)로는 더 높이 가지만, 처음 하는 아이도 올라가게 발판은 위 기준으로 놓아 주세요.
- 몬스터는 모두 `gateX`(보스 문)보다 왼쪽에 둡니다. 몬스터를 다 잡아야 문이 열립니다.
- 몬스터 종류: `basic`(초록), `fast`(빨강 날쌘돌이), `tank`(파랑 뚱보), `jumper`(보라 뜀뛰기),
  `fros`(프로스, 하늘을 나는 말벌), `spitter`(청록 침뱉기), `shield`(회색 방패병).
  - 프로스는 `{ x: 2200, type: 'fros' }` 처럼 쓰면 높이 290 에 뜹니다. `y` 를 적으면 250 ~ 340 사이에서만 납니다(그보다 높으면 못 때려서). 예전 이름 `bomber` 로 적어도 프로스가 나옵니다.
  - 지금은 프로스가 스테이지 2, 침뱉기가 3, 방패병이 4 부터 나오고 5, 7 ~ 10 에는 전부 나옵니다. 새 몬스터가 처음 나오는 곳 앞에는 안내판이나 로봇 대사를 넣어 주세요.
- 수중 몬스터(스테이지 6): `jelly`(골드해파리 GX), `puffer`(가시복어), `piranha`(이빨 피라냐)는 헤엄칩니다.
  `y` 로 높이를 정하고(170 ~ 446 사이만 됨), 안 적으면 종류마다 기본 높이. `crab`(집게 꽃게)은 바닥을 걷습니다.
- 스테이지에 `swim: true` 를 적으면 주인공이 헤엄칩니다(숫자는 `balance.js` 의 `swim`). 이때 발판은 y 190 보다 아래에 두세요(헤엄 천장 150).
- 마지막 스테이지는 `src/stage/index.js` 의 `stages` 맨 끝 스테이지입니다. 깼을 때 로봇 대사는 그 스테이지의 `endingLines`.
- 보물 `id` 는 모든 스테이지에서 겹치면 안 됩니다.
- 보물은 `id` 와 `power` 만 적습니다. 자리는 스테이지에 들어올 때마다 발판 위나 땅 위에서 무작위로 정해집니다(`src/logic/treasures.js`).
  뒤 스테이지일수록 높은 발판에 숨을 때가 많습니다. 보물 개수는 적은 줄 수만큼이고, 뒤 스테이지일수록 늘려 주세요.
- 스테이지가 하나 넘어갈 때마다 몬스터와 보스가 조금씩 세집니다(`src/logic/difficulty.js` 의 `STAGE_RAMP`).
- 보스에 `skin: 1` 처럼 적으면 그 번호 스테이지의 보스 그림을 그대로 씁니다(예: 스테이지 7 파쇄자 MK2 는 스테이지 1 그림).
- 안내판 글과 로봇 대사에 `{punch}`, `{dash}`, `{ult}`, `{up}`, `{move}`, `{jump}` 를 쓰면 고른 조작 방식의 키 이름으로 바뀝니다.
- 보스 공격 이름: `slam`(내려찍기), `multiSlam`(연속 내려찍기), `doubleSlam`(두 팔 동시), `sweep`(바닥 쓸기),
  `rocks`(돌 떨구기), `shockwave`(땅 울림, 점프로 넘기), `spit`(독침).
- `npm test` 를 돌리면 위 규칙을 어겼는지 자동으로 확인해 줍니다.
